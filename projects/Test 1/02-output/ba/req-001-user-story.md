# req-001 User Stories

## US-001 Create Product

As a warehouse staff user, I want to create a product so that the inventory list contains items that need to be managed.

## US-002 View Product List

As a warehouse staff user, I want to view products so that I know what products are currently managed.

## US-003 Search Product

As a warehouse staff user, I want to search by product code or name so that I can quickly find the product I need.

## US-004 View Product Detail

As a warehouse staff user, I want to view product detail so that I can check all product information.

## US-005 Update Product Information

As a warehouse staff user, I want to update product information so that product data stays accurate.

## US-006 Update Quantity

As a warehouse staff user, I want to update current quantity so that the system reflects real stock levels.

## US-007 Delete Product

As a warehouse staff user, I want to delete products that are no longer managed so that the inventory list stays clean.
