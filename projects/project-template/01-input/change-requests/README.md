# Change Requests

Use this folder only after the project has a stable baseline and the customer sends a change request or customization request.

Create one file per request:
- `cr-001.md`
- `cr-002.md`

Follow:
- `projects/PROJECT_CHANGE_REQUEST_GUIDE.md`
- `system/runbooks/handle-change-request.md`
- `system/templates/change-control/template-change-request.md`

Do not edit the linked requirement directly until the CR is approved, applied, verified, and merged.
