# Create Artifact

## Purpose

Create or extend an artifact contract or artifact-supporting standard through Component Factory.

## Steps

1. Check `system/artifacts/` for overlap.
2. Read factory rules and guardrails.
3. Use `runbooks/create-artifact-runbook.md`.
4. Use `templates/artifact-contract-template.md`.
5. Produce `artifacts/component-creation-report.md`.

## Prohibited Actions

- do not generate project business outputs
- do not confuse artifact contract definition with template or runbook creation
