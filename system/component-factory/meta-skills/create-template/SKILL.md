# Create Template

## Purpose

Create a new runtime template through Component Factory.

## Steps

1. Check `system/templates/` for overlap by document type.
2. Read factory rules and guardrails.
3. Use `runbooks/create-template-runbook.md`.
4. Use `templates/template-template.md`.
5. Produce `artifacts/component-creation-report.md`.

## Prohibited Actions

- do not create a template when a checklist or artifact contract would solve the problem better
- do not create near-duplicate templates with tiny wording differences
