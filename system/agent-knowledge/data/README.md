# Data Agent Knowledge

Use this folder for reusable data modeling, SQLite design, and product metric tracking preferences.

Examples:
- naming conventions for tables and fields
- audit and status transition patterns
- seed data conventions
- migration notes for local runnable apps
- metric framework selection heuristics
- event naming and property conventions
- privacy rules for analytics tracking

Project-specific data rules still belong in `projects/<project>/03-context/`.
