# PO Requirement Type Guide

Use this note when classifying requirement statements inside the BRD.

## Business Requirement

What the business must achieve or change.

## Stakeholder Requirement

What a stakeholder or user needs from that change.

## Solution Requirement

What the product or system must provide to satisfy the business and stakeholder needs.

## Transition Requirement

What is needed to move from the current state to the future state, such as rollout, migration, training, approval, or cutover support.

## Working Rule

- keep classification visible in the BRD
- if one sentence mixes requirement types, separate it or mark the ambiguity
