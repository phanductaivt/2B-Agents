# Developer Tools MCP Category

Use this category for MCPs that inspect repositories, CI, package
metadata, issue trackers, or development environments.

No developer-tools MCP is currently governed.

Git MCP is de-scoped. Local Git CLI, IDE Git features, and the existing GitHub
remote may still be used outside the MCP layer under the active task's normal
permission and safety constraints.

Before adding one:

- Create `servers/{server_name}` from templates.
- Add registry and policy entries.
- Validate read-only operations first.
- Require approval for merge, deploy, publish, or permission-changing actions.
