# Security Policy: Playwright MCP

- Prefer local/dev URLs.
- Do not run production-impacting flows without approval.
- Do not enter credentials unless the user approves the target account and
  environment.
- Do not submit payment, send messages, publish, share, delete, or change
  permissions without approval.
- Screenshots may contain sensitive data; store or share them carefully.
- Log URL, action, result, and non-sensitive errors.
