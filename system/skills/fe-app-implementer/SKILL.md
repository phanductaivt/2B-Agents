# FE App Implementer

## Use When

- the project needs a runnable React frontend
- BE API contract and UIUX wireframe are ready enough for implementation

## Output

Vite React frontend code with:
- clear screen structure
- API integration
- state handling
- validation and error states
- README run commands

## Rules

- do not guess backend endpoints if an API contract exists
- keep UI behavior aligned with BA and BE outputs
- make loading, error, and success states visible
