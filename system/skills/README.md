# Skills

Skills are reusable work patterns that agents can call.

Each skill explains:
- why it exists
- when to use it
- what input it expects
- what output it should produce
- the steps it follows
- the limits it should respect
- the expected Markdown outputs

Current skills now cover:
- PO framing, market research, BACCM analysis, requirement classification, BRD writing, and prioritization support
- BA outputs such as clarification, BPMN Mermaid, FRS, and feature breakdown
- BA quality controls such as ambiguity review, scope boundary review, rule coverage, and exception expansion
- BE outputs such as service design and API contract definition
- architecture outputs such as system shape, NFR review, and security review
- data outputs such as data model, state transition, SQLite schema planning, feature metric planning, and tracking event planning
- QA outputs such as test scenario design, test case design, and release-readiness review
- UX/UI outputs such as wireframe guidance
- FE outputs such as simple HTML implementation, FE state planning, FE validation mapping, and FE API usage planning
- runnable implementation outputs such as FastAPI code, Vite React code, smoke checks, and runnable verification

This makes the system easier to scale without rewriting the whole playbook each time.
