# Checklist - Clarification

- [ ] Problem insight is clear.
- [ ] Current pain point is clear.
- [ ] Problem statement is clear.
- [ ] Primary actor or stakeholder is clear.
- [ ] Expected business value is clear.
- [ ] Scope boundaries are clear.
- [ ] Missing or conflicting business rules are visible.
- [ ] Facts, assumptions, and open questions are separated.
- [ ] Blocking questions are listed, or the artifact explains why none are needed.
- [ ] Non-blocking questions are listed with matching assumptions.
- [ ] Each question is classified as blocking, non-blocking, or assumption-backed.
- [ ] Recommended decision is one of `Proceed`, `Proceed with assumptions`, or `Blocked`.
- [ ] User approval status is one of `Pending User Approval`, `Approved - Proceed`, `Approved - Proceed with assumptions`, or `Blocked`.
- [ ] Downstream work is blocked unless user approval is explicit.
- [ ] Downstream readiness notes explain whether later agents may continue.
- [ ] Final response identifies the review file path.
- [ ] Final response lists the exact sections the user should inspect.
- [ ] Final response states the allowed approval replies.
- [ ] Missing success criteria are visible if still unresolved.
- [ ] Key assumptions are listed.
- [ ] Open questions are listed.
- [ ] Requirement ID is shown.
