# Checklist - Test Cases

- [ ] Test case objective is clear.
- [ ] Preconditions are visible.
- [ ] Steps are reproducible.
- [ ] Expected results are specific and observable.
- [ ] Evidence or execution record expectations are visible.
- [ ] Automation candidate and automation priority are stated.
- [ ] Positive, negative, and validation-sensitive behavior is covered where relevant.
- [ ] Linked scenario and source artifact IDs are shown.
